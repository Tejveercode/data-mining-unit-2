## Part A — 2-mark questions (define / list / one-line difference)

1. Define data pre-processing. **→** operations that convert raw data into a clean, consistent, usable form for mining; sits between collection and model building.
2. Why is pre-processing called the most time-consuming step? **→** 60–80 % of effort; real data is incomplete, noisy, inconsistent and huge.
3. List any four data-quality dimensions. **→** accuracy, completeness, consistency, timeliness (also believability, interpretability).
4. Define noise. **→** random error or variance in a measured value that obscures the true pattern.
5. Define an outlier. **→** a data point that deviates so much from others that it appears generated by a different mechanism.
6. Differentiate noise and outlier. **→** noise = small random error, frequent, fixed by smoothing; outlier = extreme rare point, fixed by detection/treatment.
7. What is a missing value? **→** no data stored for an attribute in an observation (`NULL`, blank, `?`).
8. Define MCAR. **→** missingness unrelated to any data, observed or unobserved.
9. Define MAR. **→** missingness depends on other observed attributes, not on the missing value itself.
10. Define MNAR. **→** missingness depends on the missing value itself (high earners refusing income).
11. What is imputation? **→** replacing a missing value with an estimated plausible value.
12. Define data integration. **→** combining data from multiple sources into a single unified view.
13. What is schema integration? **→** merging attributes/tables/structures from different sources into one unified schema.
14. Give an example of a naming conflict. **→** `CustID` vs `Customer_ID` for the same attribute.
15. Give an example of a homonym. **→** `Name` meaning product name in one table and person name in another.
16. Define data redundancy. **→** the same data appearing multiple times across attributes or records.
17. How is redundancy detected between two numeric attributes? **→** correlation coefficient; `|r| > 0.9` suggests redundancy.
18. Which test detects redundancy between two nominal attributes? **→** χ² (chi-square) test of independence.
19. Define data reduction. **→** reducing data size/complexity while preserving essential patterns.
20. What is a data cube? **→** a multidimensional structure of dimensions and measures supporting aggregation and OLAP.
21. Name the three levels of a data cube. **→** base, intermediate, apex.
22. List four OLAP operations. **→** roll-up, drill-down, slice, dice (and pivot).
23. Define sampling. **→** selecting a representative subset of data instead of the whole dataset.
24. What is stratified sampling? **→** divide the population into homogeneous groups (strata) and sample proportionally within each.
25. What is reservoir sampling used for? **→** a fixed-size uniform sample from a stream of unknown length in one pass.
26. Define attribute subset selection. **→** keeping only the most relevant attributes, removing irrelevant/redundant ones.
27. Name the three families of feature-selection methods. **→** filter, wrapper, embedded.
28. Give two examples of embedded methods. **→** Lasso (L1), decision-tree/random-forest importance.
29. Differentiate feature selection and feature extraction. **→** selection keeps original attributes; extraction creates new combined features (PCA, SVD).
30. Define normalization. **→** scaling numeric attributes to a standard range without distorting relative differences.
31. Write the min–max normalization formula. **→** `(v − min)/(max − min)`.
32. Write the z-score formula. **→** `(v − μ)/σ`.
33. When is median imputation preferred to mean? **→** when the attribute is skewed or contains outliers.
34. What is one-hot encoding? **→** one binary column per category, 1 for presence, 0 otherwise.
35. Why is label encoding risky for nominal data? **→** it imposes a false order/magnitude that models may treat as numeric.
36. Define discretization. **→** dividing a continuous attribute's range into intervals mapped to categories.
37. What is binarization? **→** discretization into exactly two intervals.
38. Define a concept hierarchy. **→** values organised from specific to general, forming a tree of levels.
39. Define support. **→** the fraction of transactions containing an itemset: `σ(X)/N`.
40. Define confidence. **→** `σ(X∪Y)/σ(X)` — how often Y holds given X.
41. Define lift. **→** `s(X∪Y)/(s(X)s(Y))`; 1 = independence, >1 positive, <1 negative.
42. State the Apriori property. **→** if an itemset is frequent, all its subsets are frequent; equivalently, a superset of an infrequent itemset is infrequent.
43. Why is the Apriori property called anti-monotonic? **→** support never increases as items are added.
44. What is an FP-tree? **→** a compressed prefix tree of transactions with node counts and a header table of item links.
45. How many database scans does FP-Growth need? **→** two.
46. What is a conditional pattern base? **→** the set of prefix paths (with counts) reaching a given item in the FP-tree.
47. What is a closed frequent itemset? **→** a frequent itemset with no proper superset of the same support.
48. What is a maximal frequent itemset? **→** a frequent itemset with no frequent proper superset.
49. Define leverage. **→** `s(X∪Y) − s(X)s(Y)`; 0 = independence.
50. What does lift = 1 mean? **→** X and Y are statistically independent.

## Part E — Viva / one-liners an examiner may spring

- *Why not just use all attributes?* → overfitting, cost, uninterpretable models, noise.
- *Why standardize before PCA?* → PCA maximises variance, so a large-unit attribute would dominate.
- *Why is support anti-monotonic?* → containing a superset implies containing every subset.
- *Can lift be less than 1 for a strong rule?* → Yes — strong by confidence, but negatively associated; not interesting.
- *Is a maximal itemset always closed?* → Yes (no frequent proper superset ⇒ no same-support superset); the converse is false.
- *Why does FP-Growth still need minsup?* → the tree only drops infrequent 1-items; mining still thresholds support, and low minsup grows the tree.
- *What is the biggest risk in pre-processing?* → leakage: fitting transformations on data you later test on.
- *Which sampling method protects a rare class?* → stratified sampling.
- *Why is mean imputation bad for income?* → skewed distribution plus outliers; use median or model-based.
- *Why not delete all rows with missing values?* → loses data and biases the sample unless missingness is MCAR.
